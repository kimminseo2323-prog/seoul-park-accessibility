## [2.3] - 2025-12-29

### 추가 (Added)

#### 다중 버퍼 및 공원 유형별 분석
- **새로운 데이터 파일**: `dong_service_score_multi_buffer_parktype.csv` (8,075개 레코드)
  - 426개 행정동 × 4개 버퍼 거리 × 공원 유형별 조합
  - 버퍼 거리: 100m, 300m, 500m, 1000m
  - 공원 유형: '전체', '근린공원', '어린이공원', '소공원' 등
- **최적화된 분석 스크립트**: `s2_module/3_다중버퍼_공원유형별_분석_최적화.py`
  - Spatial indexing 적용
  - 버퍼 사전 계산 및 재사용
  - 실행 시간: 무한 루프 → 10~30분

#### 새로운 차트 3종 추가
1. **버퍼별 평균 접근성 변화**
   - 100m, 300m, 500m, 1000m 거리별 평균 접근성 추세 라인 차트
   - 시군구 및 공원 유형 필터링 가능
   - 콜백 함수: `update_buffer_avg_accessibility_chart()` (Lines 1577-1641)

2. **시군구별 지니계수 비교**
   - 각 시군구 내부의 불평등 정도 측정
   - 상위 10개 시군구 막대 차트 표시
   - 지니계수 계산식 적용: `G = (2 * Σ(i × x_i)) / (n × Σ(x_i)) - (n+1)/n`
   - 콜백 함수: `update_sigungu_gini_chart()` (Lines 1649-1707)

3. **상위/하위 5개 동 비교**
   - 최고 접근성 5개 동 vs 최저 접근성 5개 동
   - 수평 막대 차트로 격차 시각화
   - 콜백 함수: `update_top_bottom_comparison_chart()` (Lines 1716-1790)

#### 데이터 로더 개선
- `data_loader.py`: `load_2sfca_multi_buffer()` 메서드 추가
- `config.py`: `CSV_2SFCA_MULTI` 경로 상수 추가

### 수정 (Fixed)

#### 버그 수정
1. **상단 지표 미표시 문제** (초기 값 0.0000)
   - 원인: `sigungu-select` 초기 값 설정 및 콜백 의존성 문제
   - 해결: 레이아웃에서 직접 옵션 로드, 중복 콜백 제거

2. **공원 유형 선택 시 차트 미표시 문제**
   - 원인: Line 1021에서 `gdf_filtered` 존재하지 않는 변수 참조
   - 해결: `df_filtered`로 수정 및 집계 로직 단순화

3. **무의미한 차트 제거**
   - 제거된 차트:
     - 버퍼별 인구 커버리지 비교 (거의 100%로 평평)
     - 공원 유형별 서비스 기여도 (대부분 0 값)
     - 접근성 점수 분포 (0-100 구간에만 집중)
   - 대체: 위의 3가지 새로운 의미 있는 차트

4. **Background 분석 스크립트 무한 루프 문제**
   - 원인: 비효율적인 중첩 루프 및 반복적인 버퍼 재계산
   - 해결: 최적화 스크립트 생성 (`3_다중버퍼_공원유형별_분석_최적화.py`)
