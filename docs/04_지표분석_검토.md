## 1. 서비스 접근성 점수 (avg_service_per_capita)

### 계산 과정
```python
# Step 1: 공원별 공급-수요 비율 계산
R_j = park_area_m2 / total_demand
# total_demand = 버퍼 내 모든 격자의 인구 합계

# Step 2: 격자별 서비스 점수 계산
for grid in dong_grids:
    service_score += R_j * grid_pop  # 인구 가중치 적용

# Step 3: 행정동별 1인당 평균
avg_service = service_score / total_pop  # 전체 인구로 나눔
```

### 인구 반영 확인
✅ **완전히 반영됨**

1. **공급-수요 비율 (R_j)**: 버퍼 내 총인구를 분모로 사용
   - 인구가 많을수록 R_j 감소 (공급 부족)
   - 인구가 적을수록 R_j 증가 (공급 여유)

2. **격자별 가중 합산**: 각 격자의 서비스 점수에 해당 격자 인구를 곱함
   - 인구가 많은 격자의 영향력이 큼
   - 인구 0인 격자는 영향 없음

3. **1인당 평균**: 총 서비스 점수를 전체 인구로 나눔
   - 단위: m²/인 (1인당 접근 가능한 공원 면적)

### 결론
**인구 대비 접근성 지표임** ✅
- 해당 행정동의 총인구 대비 1인당 평균 서비스 면적
- 인구 분포와 밀도가 완전히 반영됨

## 2. 커버리지 비율 (coverage_ratio)

### 계산 과정
```python
covered_pop = dong_grids[dong_grids['gid'].isin(covered_grids)]['val'].sum()
coverage_ratio = (covered_pop / total_pop) * 100
```

### 인구 반영 확인
✅ **완전히 반영됨**

- `covered_pop`: 버퍼 내에 있는 격자들의 실제 인구 합계
- `total_pop`: 행정동의 전체 인구
- **비율 = 서비스 범위 내 인구 / 전체 인구**

### 결론
**총인구 대비 서비스 수혜 인구 비율임** ✅

## 3. 지니 계수 (Gini Coefficient)

### 계산 과정
```python
def gini_coefficient(x):
    x = np.array(x)  # 서비스 점수 배열
    x = x[x > 0]     # 0 제외
    x = np.sort(x)   # 오름차순 정렬
    n = len(x)       # 지역 개수
    index = np.arange(1, n + 1)
    return (2 * np.sum(index * x)) / (n * np.sum(x)) - (n + 1) / n
```

### 인구 반영 확인
⚠️ **지역 수 기준, 인구 가중치 미적용**

#### 현재 방식
- **Input**: 426개 행정동(또는 25개 시군구)의 서비스 점수 배열
- **계산**: 지역 수(n)를 기준으로 불평등도 측정
- **의미**: "지역 간" 서비스 점수 분포의 불평등

#### 특징
1. 모든 지역을 동등하게 취급 (1지역 = 1 단위)
2. 인구 10만 명 지역과 인구 1만 명 지역이 같은 가중치
3. 행정동/시군구별 비교 시 적합

#### 대안 (인구 가중 Gini)
만약 인구를 반영하려면:
```python
def population_weighted_gini(scores, populations):
    """인구 가중 Gini 계수"""
    # scores: 서비스 점수
    # populations: 각 지역 인구

    # 인구로 정렬
    sorted_idx = np.argsort(scores)
    sorted_scores = scores[sorted_idx]
    sorted_pop = populations[sorted_idx]

    # 누적 인구 및 서비스
    cum_pop = np.cumsum(sorted_pop) / np.sum(sorted_pop)
    cum_service = np.cumsum(sorted_scores * sorted_pop) / np.sum(sorted_scores * sorted_pop)

    # 로렌츠 곡선 면적
    area = np.sum((cum_service[:-1] + cum_service[1:]) * np.diff(cum_pop)) / 2
    return 1 - 2 * area
```

### 결론
**현재: 지역 수 기준 불평등도** ⚠️
- 지역 간 서비스 격차 측정에 적합
- 인구 고려 안 됨 (작은 지역과 큰 지역 동등 비교)

**대안: 인구 가중 방식 구현 가능**
- 인구 밀집 지역의 불평등을 더 중요하게 반영
- 필요 시 추가 구현 권장

## 4. 시군구별 집계

### 계산 과정
```python
sigungu_stats = dong_service_df.groupby('SIGUNGU_NM').agg({
    'total_population': 'sum',           # 인구 합계
    'covered_population': 'sum',         # 커버된 인구 합계
    'avg_service_per_capita': 'mean'     # 서비스 점수 평균
}).reset_index()

sigungu_stats['coverage_ratio'] = (
    sigungu_stats['covered_population'] /
    sigungu_stats['total_population'] * 100
)
```

### 인구 반영 확인
⚠️ **부분적으로 반영됨**

#### 올바른 부분
- `total_population`: 시군구 전체 인구 ✅
- `covered_population`: 시군구 내 커버된 인구 ✅
- `coverage_ratio`: 인구 비율 정확함 ✅

#### 주의할 부분
- `avg_service_per_capita`: **행정동 평균값의 산술 평균** ⚠️
- 인구 가중 평균이 아님!

#### 예시
```
강남구:
  - 삼성동: avg_service = 10 m²/인, 인구 20,000명
  - 역삼동: avg_service = 20 m²/인, 인구 10,000명

현재 계산: (10 + 20) / 2 = 15 m²/인 (산술 평균)
올바른 계산: (10×20,000 + 20×10,000) / 30,000 = 13.33 m²/인 (가중 평균)
```

### 개선 방안
```python
sigungu_stats = dong_service_df.groupby('SIGUNGU_NM').apply(
    lambda x: pd.Series({
        'total_population': x['total_population'].sum(),
        'covered_population': x['covered_population'].sum(),
        'avg_service_per_capita': (
            (x['avg_service_per_capita'] * x['total_population']).sum() /
            x['total_population'].sum()
        )  # 인구 가중 평균
    })
).reset_index()
```

### 결론
**시군구 서비스 점수는 인구 가중 평균으로 수정 필요** ⚠️
