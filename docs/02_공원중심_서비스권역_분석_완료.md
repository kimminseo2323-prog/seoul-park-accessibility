> **상태**: ✅ 완료 (2025-12-29)

> **구현 위치**: `s2_module/`, `s9_bi/`
> **버전**: 2.4

## 🎯 분석 관점의 전환

### ❌ 기존 방식 (주민 → 공원)
"주민이 공원에 얼마나 쉽게 접근할 수 있는가?"
- 행정동 중심점에서 공원까지 거리
- 문제: 공원의 서비스 제공 능력 무시

### ✅ 새로운 방식 (공원 → 주민)
"**공원이 주변 주민들에게 얼마나 많은 서비스를 제공하는가?**"
- **공원 경계에서 버퍼 확장** → 서비스 권역 설정
- **권역 내 인구 파악** → 공원이 수용하는 인구수
- **행정동/시군구별 집계** → 어느 지역이 공원 서비스를 더 많이 받는가?

## 📚 학술적 근거

### 핵심 개념: **공원 서비스 공급-수요 비율 (Supply-Demand Ratio)**

#### 2SFCA 방법론 (Two-Step Floating Catchment Area)

**Step 1: 공원별 수용 가능 인구 대비 공급량 계산**
```
R_j = S_j / Σ(P_k × G(d_jk))

R_j: 공원 j의 공급-수요 비율 (m²/인)
S_j: 공원 j의 면적 (m²)
P_k: 서비스 권역 내 격자 k의 인구
G(d_jk): Gaussian 거리 감쇠 함수
d_jk: 공원 j에서 격자 k까지 거리
```

**Step 2: 행정동별 서비스 수혜도 계산**
```
A_i = Σ(R_j × G(d_ij) × 1_버퍼내)

A_i: 행정동 i의 공원 서비스 수혜 점수
R_j: 공원 j의 공급-수요 비율
G(d_ij): 거리 감쇠 가중치
1_버퍼내: 행정동이 공원 버퍼 내에 있으면 1, 아니면 0
```

## 📐 분석 설계

### 지표 1: 공원별 서비스 권역 인구 (Park Service Population)

#### 정의
공원 경계에서 일정 거리 내에 거주하는 총 인구수

#### 계산 방법
```python
for park_j in all_parks:
    # 공원 경계에서 버퍼 생성
    buffer_300m = park_j.geometry.buffer(300)
    buffer_500m = park_j.geometry.buffer(500)
    buffer_1km = park_j.geometry.buffer(1000)

    # 각 버퍼 내 격자 찾기
    grids_300m = grids[grids.within(buffer_300m)]
    grids_500m = grids[grids.within(buffer_500m)]
    grids_1km = grids[grids.within(buffer_1km)]

    # 인구 합계
    pop_300m = grids_300m['val'].sum()
    pop_500m = grids_500m['val'].sum()
    pop_1km = grids_1km['val'].sum()
```

#### 출력
- `park_id`: 공원 ID
- `park_name`: 공원명
- `park_area_km2`: 공원 면적 (km²)
- `served_pop_300m`: 300m 내 서비스 인구
- `served_pop_500m`: 500m 내 서비스 인구
- `served_pop_1km`: 1km 내 서비스 인구

#### 해석
- **높은 수치**: 많은 주민이 해당 공원을 이용 가능 → 수요 압박 높음
- **낮은 수치**: 공원이 덜 활용됨 → 신규 공원 필요성 낮음

### 지표 2: 공원 1인당 서비스 면적 (Park Supply per Capita)

#### 정의
공원 면적을 서비스 권역 내 인구수로 나눈 값

#### 계산 방법
```python
supply_per_capita_500m = park_area_m2 / served_pop_500m  # m²/인

# Gaussian 가중치 적용 (거리 감쇠)
weighted_supply = park_area_m2 / Σ(population_k × G(distance_jk))
```

#### 출력
- `supply_per_capita_300m`: m²/인 (300m 권역 기준)
- `supply_per_capita_500m`: m²/인 (500m 권역 기준)
- `supply_per_capita_1km`: m²/인 (1km 권역 기준)

#### 해석
- **WHO 권장**: 9 m²/인 이상
- **높은 수치**: 공원 수용 능력 우수, 여유 있음
- **낮은 수치**: 과밀, 공원 확충 필요

---

### 지표 3: 행정동별 공원 서비스 수혜도 (District Service Score)

#### 정의
행정동 내 격자들이 주변 공원으로부터 받는 서비스의 총합

#### 계산 방법 (2SFCA 기반)

**Step 1: 공원별 공급-수요 비율**
```python
for park_j in all_parks:
    # 500m 버퍼 내 인구
    grids_in_buffer = grids[grids.within(park_j.buffer(500))]
    total_demand = grids_in_buffer['val'].sum()

    # 공급-수요 비율
    if total_demand > 0:
        R_j = park_area_j / total_demand  # m²/인
    else:
        R_j = 0
```

**Step 2: 행정동별 서비스 점수 집계**
```python
for dong_i in all_dongs:
    # 행정동 내 격자들
    grids_in_dong = grids[grids.within(dong_i)]

    service_score = 0

    for grid_k in grids_in_dong:
        # 격자 주변 공원들
        nearby_parks = parks[parks.buffer(500).contains(grid_k.centroid)]

        for park_j in nearby_parks:
            # 공원의 공급-수요 비율 × 격자 인구
            service_score += R_j × grid_k['val']

    # 행정동 평균 (1인당)
    avg_service_score = service_score / grids_in_dong['val'].sum()
```

#### 출력
- `dong_name`: 행정동명
- `total_service_score`: 총 서비스 점수
- `avg_service_per_capita`: 1인당 평균 서비스 점수 (m²/인)
- `service_rank`: 서비스 수혜 순위

#### 해석
- **높은 점수**: 주변 공원이 많고 여유 있음 → 접근성 우수
- **낮은 점수**: 주변 공원이 적거나 과밀 → 공원 부족

---

### 지표 4: 인구 커버리지 비율 (Population Coverage Ratio)

#### 정의
전체 인구 중 공원 서비스 권역 내에 거주하는 인구 비율

#### 계산 방법
```python
# 행정동별
for dong_i in all_dongs:
    grids_in_dong = grids[grids.within(dong_i)]
    total_pop = grids_in_dong['val'].sum()

    # 500m 내 공원이 있는 격자
    covered_grids = grids_in_dong[
        grids_in_dong.apply(lambda g:
            any(parks.buffer(500).contains(g.centroid)), axis=1)
    ]
    covered_pop = covered_grids['val'].sum()

    coverage_ratio = (covered_pop / total_pop) * 100  # %
```

#### 출력
- `total_population`: 총 인구
- `covered_pop_300m`: 300m 내 공원 있는 인구
- `covered_pop_500m`: 500m 내 공원 있는 인구
- `covered_pop_1km`: 1km 내 공원 있는 인구
- `coverage_ratio_500m`: 커버리지 비율 (%)

#### 해석
- **100%**: 모든 주민이 500m 내 공원 접근 가능
- **50%**: 절반만 공원 서비스 수혜
- **목표**: 80% 이상 (서울시 공원녹지 기본계획)

---

### 지표 5: 공원 서비스 형평성 (Service Equity)

#### Gini 계수
```python
from scipy.stats import gini

# 행정동별 1인당 공원 서비스 면적
service_per_capita = [dong['avg_service_per_capita'] for dong in dongs]

gini_coefficient = gini(service_per_capita)
```

#### 해석
- **0**: 완전 평등 (모든 행정동이 동일한 서비스)
- **1**: 완전 불평등
- **목표**: 0.3 이하

## 💻 구현 알고리즘

### 알고리즘 1: 공원별 서비스 인구 계산

```python
def calculate_park_service_population(parks_gdf, grid_gdf,
                                     buffer_distances=[300, 500, 1000]):
    """
    공원별 서비스 권역 내 인구 계산

    Parameters:
    -----------
    parks_gdf : GeoDataFrame
        공원 데이터
    grid_gdf : GeoDataFrame
        100m 격자 인구 데이터
    buffer_distances : list
        버퍼 거리 [300, 500, 1000]

    Returns:
    --------
    DataFrame : 공원별 서비스 인구
    """
    import numpy as np
    from scipy.spatial import cKDTree

    results = []

    # 격자 중심점 좌표 배열
    grid_centroids = grid_gdf.geometry.centroid
    grid_coords = np.array([[pt.x, pt.y] for pt in grid_centroids])
    grid_tree = cKDTree(grid_coords)

    print(f"총 {len(parks_gdf):,}개 공원 처리 중...")

    for idx, park in parks_gdf.iterrows():
        if idx % 100 == 0:
            print(f"  진행: {idx}/{len(parks_gdf)} ({idx/len(parks_gdf)*100:.1f}%)")

        park_geom = park.geometry
        park_area_km2 = park['df_park_area_km2']

        service_pop = {}

        # 각 버퍼 거리별 서비스 인구 계산
        for dist in buffer_distances:
            buffer = park_geom.buffer(dist)

            # 버퍼 내 격자 찾기
            grids_in_buffer = grid_gdf[grid_gdf.geometry.centroid.within(buffer)]

            # 인구 합계
            total_pop = grids_in_buffer['val'].sum()
            service_pop[f'pop_{dist}m'] = int(total_pop)

            # 1인당 면적
            if total_pop > 0:
                service_pop[f'supply_per_capita_{dist}m'] = round(
                    (park_area_km2 * 1_000_000) / total_pop, 2
                )
            else:
                service_pop[f'supply_per_capita_{dist}m'] = 0

        results.append({
            'park_id': park.get('ID', idx),
            'park_name': park['LABEL'],
            'park_area_km2': park_area_km2,
            **service_pop
        })

    return pd.DataFrame(results)
```

### 알고리즘 2: 행정동별 서비스 수혜도 (2SFCA)

```python
def calculate_dong_service_score_2SFCA(parks_gdf, grid_gdf, dong_gdf,
                                       buffer_distance=500):
    """
    2SFCA 방법으로 행정동별 공원 서비스 수혜도 계산

    Parameters:
    -----------
    parks_gdf : GeoDataFrame
        공원 데이터
    grid_gdf : GeoDataFrame
        100m 격자 인구 데이터
    dong_gdf : GeoDataFrame
        행정동 경계 데이터
    buffer_distance : int
        서비스 권역 거리 (m)

    Returns:
    --------
    GeoDataFrame : 행정동별 서비스 점수
    """
    # Step 1: 공원별 공급-수요 비율 계산
    park_supply_demand_ratio = {}

    for idx, park in parks_gdf.iterrows():
        park_geom = park.geometry
        park_area_m2 = park['df_park_area_km2'] * 1_000_000

        buffer = park_geom.buffer(buffer_distance)

        # 버퍼 내 격자
        grids_in_buffer = grid_gdf[grid_gdf.geometry.centroid.within(buffer)]
        total_demand = grids_in_buffer['val'].sum()

        if total_demand > 0:
            R_j = park_area_m2 / total_demand  # m²/인
        else:
            R_j = 0

        park_supply_demand_ratio[idx] = R_j

    # Step 2: 격자에 행정동 정보 추가 (Spatial Join)
    grid_with_dong = gpd.sjoin(
        grid_gdf,
        dong_gdf[['ADM_NM', 'SIGUNGU_NM', 'geometry']],
        how='left',
        predicate='within'
    )

    # Step 3: 행정동별 서비스 점수 집계
    dong_results = []

    for dong_name in dong_gdf['ADM_NM'].unique():
        dong_grids = grid_with_dong[grid_with_dong['ADM_NM'] == dong_name]
        total_pop = dong_grids['val'].sum()

        if total_pop == 0:
            continue

        service_score = 0
        covered_pop = 0

        for _, grid in dong_grids.iterrows():
            grid_centroid = grid.geometry.centroid
            grid_pop = grid['val']

            # 격자 주변 공원 찾기
            for park_idx, park in parks_gdf.iterrows():
                buffer = park.geometry.buffer(buffer_distance)

                if grid_centroid.within(buffer):
                    # 공원의 공급-수요 비율 × 격자 인구
                    R_j = park_supply_demand_ratio[park_idx]
                    service_score += R_j * grid_pop

                    # 커버된 인구 (중복 방지를 위해 한번만 카운트)
                    if covered_pop == 0 or grid_pop not in [covered_pop]:
                        covered_pop += grid_pop
                    break  # 가장 가까운 공원만 적용

        # 1인당 평균
        avg_service = service_score / total_pop if total_pop > 0 else 0
        coverage_ratio = (covered_pop / total_pop) * 100 if total_pop > 0 else 0

        dong_results.append({
            'ADM_NM': dong_name,
            'SIGUNGU_NM': dong_grids['SIGUNGU_NM'].iloc[0],
            'total_population': int(total_pop),
            'covered_population': int(covered_pop),
            'coverage_ratio': round(coverage_ratio, 2),
            'total_service_score': round(service_score, 2),
            'avg_service_per_capita': round(avg_service, 2),
            'geometry': dong_gdf[dong_gdf['ADM_NM'] == dong_name].iloc[0].geometry
        })

    result_gdf = gpd.GeoDataFrame(dong_results, crs=dong_gdf.crs)

    # 순위 계산
    result_gdf['service_rank'] = result_gdf['avg_service_per_capita'].rank(
        ascending=False, method='min'
    ).astype(int)

    return result_gdf.sort_values('service_rank')
```

### 알고리즘 3: 시군구별 집계

```python
def aggregate_to_sigungu(dong_service_gdf):
    """
    행정동 데이터를 시군구로 집계

    Returns:
    --------
    DataFrame : 시군구별 통계
    """
    sigungu_stats = dong_service_gdf.groupby('SIGUNGU_NM').agg({
        'total_population': 'sum',
        'covered_population': 'sum',
        'avg_service_per_capita': 'mean'
    }).reset_index()

    # 커버리지 비율 재계산
    sigungu_stats['coverage_ratio'] = (
        sigungu_stats['covered_population'] /
        sigungu_stats['total_population'] * 100
    ).round(2)

    # 순위
    sigungu_stats['rank'] = sigungu_stats['avg_service_per_capita'].rank(
        ascending=False
    ).astype(int)

    # Gini 계수
    from scipy.stats import gini
    gini_coef = gini(sigungu_stats['avg_service_per_capita'])

    return sigungu_stats.sort_values('rank'), gini_coef
```
