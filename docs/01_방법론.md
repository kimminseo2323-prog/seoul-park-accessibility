## 핵심 방법론: 2SFCA (Two-Step Floating Catchment Area)

### 개념적 배경

2SFCA는 **공급(공원)과 수요(인구)의 공간적 상호작용**을 동시에 고려하는 접근성 측정 방법론입니다. 단순히 "가까운 공원이 있는가?"를 넘어 "그 공원을 이용하려는 인구가 얼마나 많은가?"를 반영합니다.

### 학술적 근거

- **개발자**: Luo, W., & Wang, F. (2003)
- **원래 적용 분야**: 의료 서비스 접근성 분석
- **도시공원 적용**: MDPI Land (2022), PLOS ONE (2024) 등 다수 연구

**핵심 개념**:
- 공원이 클수록 더 많은 서비스 제공
- 주변 인구가 많을수록 공원 당 서비스 감소 (혼잡 효과)
- 거리가 멀수록 접근성 감소 (거리 감쇠)

### Step 1: 공원별 공급-수요 비율 계산

각 공원 j에 대해 서비스 영역(버퍼) 내 인구로 공원 면적을 나눕니다.

```
R_j = S_j / Σ(P_k)
```

**변수 정의**:
- `R_j`: 공원 j의 1인당 서비스 공급량 (m²/인)
- `S_j`: 공원 j의 서비스 용량 (면적, m²)
- `P_k`: 버퍼 d₀ 내 격자 k의 인구
- `Σ(P_k)`: 버퍼 내 전체 인구 합계

**실제 계산 예시**:
```python
# 공원 A
- 면적: 10,000 m²
- 500m 버퍼 내 인구: 5,000명
- R_A = 10,000 / 5,000 = 2.0 m²/인

# 공원 B
- 면적: 20,000 m²
- 500m 버퍼 내 인구: 15,000명
- R_B = 20,000 / 15,000 = 1.33 m²/인
```

**해석**: 공원 A는 B보다 작지만, 주변 인구가 적어 1인당 공급량이 더 높음

### Step 2: 인구 격자별 접근성 점수 계산

각 인구 격자 i에 대해 버퍼 내 모든 공원의 R 값을 합산합니다.

```
A_i = Σ(R_j)  for all j where d_ij ≤ d₀
```

**변수 정의**:
- `A_i`: 격자 i의 접근성 점수 (m²/인)
- `Σ(R_j)`: 격자 i로부터 버퍼 d₀ 내 모든 공원 j의 R 값 합계
- `d_ij`: 격자 i에서 공원 j까지의 거리
- `d₀`: 버퍼 거리 임계값 (예: 500m)

**실제 계산 예시**:
```python
# 격자 X
- 500m 내 공원 A(R=2.0), 공원 B(R=1.33) 존재
- A_X = 2.0 + 1.33 = 3.33 m²/인

# 격자 Y
- 500m 내 공원 B(R=1.33)만 존재
- A_Y = 1.33 m²/인
```

### Step 3: 행정동별 평균 접근성 집계

행정동 단위로 인구 가중 평균을 계산합니다.

```
avg_service = Σ(A_i × P_i) / Σ(P_i)
```

**변수 정의**:
- `avg_service`: 행정동의 평균 서비스 점수 (m²/인)
- `A_i`: 행정동 내 격자 i의 접근성 점수
- `P_i`: 격자 i의 인구
- `Σ(P_i)`: 행정동 전체 인구

**인구 가중 평균의 중요성**:
```python
# 예시: 행정동 A (총 인구 10,000명)
- 격자 1: 접근성 5.0, 인구 100명 → 기여도 = 5.0 × 100 = 500
- 격자 2: 접근성 2.0, 인구 9,900명 → 기여도 = 2.0 × 9,900 = 19,800
- 행정동 A 평균 = (500 + 19,800) / 10,000 = 2.03 m²/인

# 단순 평균 사용 시: (5.0 + 2.0) / 2 = 3.5 (부정확!)
```

**교훈**: 인구가 많은 지역의 접근성이 전체 평균에 더 큰 영향을 미쳐야 함

## 형평성 분석 지표

### 1. 지니 계수 (Gini Coefficient)

**개념**: 공원 서비스 접근성의 지역 간 불평등 정도를 0~1 사이의 값으로 측정

**계산 공식**:
```
G = (1 / (2n²μ)) × Σ Σ |x_i - x_j|
```

**변수 정의**:
- `n`: 전체 행정동 수 (424개)
- `μ`: 평균 서비스 점수
- `x_i, x_j`: 각 행정동의 서비스 점수
- `Σ Σ`: 모든 행정동 쌍의 절대 차이를 합산

**Python 구현**:
```python
def calculate_gini_coefficient(values):
    """
    지니 계수 계산

    Parameters:
    -----------
    values : array-like
        행정동별 서비스 점수

    Returns:
    --------
    float : 지니 계수 (0~1)
    """
    values = np.array(values).flatten()
    if np.amin(values) < 0:
        values -= np.amin(values)  # 음수 값 제거

    values = np.sort(values)  # 오름차순 정렬
    n = len(values)
    index = np.arange(1, n + 1)

    return (2 * np.sum(index * values)) / (n * np.sum(values)) - (n + 1) / n
```

**해석 기준**:
| 지니 계수 범위 | 불평등 수준 | 정책적 의미 |
|---------------|------------|------------|
| 0.00 ~ 0.20 | 매우 평등 | 유지 관리 필요 |
| 0.20 ~ 0.30 | 평등 | 부분적 개선 검토 |
| 0.30 ~ 0.40 | 보통 | 저접근성 지역 개선 필요 |
| 0.40 ~ 0.50 | 불평등 | 공원 확충 정책 필요 |
| 0.50 ~ 1.00 | 매우 불평등 | 긴급 정책 개입 필요 |

### 2. 로렌츠 곡선 (Lorenz Curve)

**개념**: 지니 계수를 시각적으로 표현한 누적 분포 곡선

**계산 방법**:
```python
def calculate_lorenz_curve(values):
    """
    로렌츠 곡선 계산

    Returns:
    --------
    cum_pop_pct : array
        누적 인구 비율 (0~100%)
    cum_service_pct : array
        누적 서비스 점수 비율 (0~100%)
    """
    # 1. 오름차순 정렬
    sorted_values = np.sort(values)

    # 2. 누적 합계
    cum_values = np.cumsum(sorted_values)
    total = cum_values[-1]

    # 3. 백분율 변환
    cum_pop_pct = np.linspace(0, 100, len(values))
    cum_service_pct = (cum_values / total) * 100

    return cum_pop_pct, cum_service_pct
```

**시각화**:
- X축: 누적 인구 비율 (0% → 100%)
- Y축: 누적 서비스 점수 비율 (0% → 100%)
- 완전 평등선: 45도 대각선 (빨간 점선)
- 로렌츠 곡선: 실제 데이터 (파란 실선)

**해석**:
- 곡선이 대각선에 가까울수록: 평등
- 곡선이 대각선에서 멀수록: 불평등
- 지니 계수 = (대각선과 곡선 사이 면적) / (대각선 아래 삼각형 면적)

**대시보드 적용**:
- 시군구별 로렌츠 곡선: 25개 자치구의 형평성 분석
- 행정동별 로렌츠 곡선: 426개 행정동의 세밀한 불평등 측정
- 버퍼 거리 및 공원 유형별 필터링 가능
- 지니계수 자동 계산 및 차트 제목에 표시

### 3. 커버리지 비율 (Coverage Ratio)

**개념**: 행정동/시군구 내 전체 인구 중 몇 %가 공원 서비스 범위 내에 거주하는지 측정

**계산 공식**:
```
coverage_ratio = (covered_population / total_population) × 100
```

**Python 구현**:
```python
def calculate_coverage_ratio(grid_gdf, park_gdf, dong_gdf, buffer_distance=500):
    """
    행정동별 커버리지 비율 계산

    Returns:
    --------
    DataFrame : 행정동별 커버리지 비율
    """
    results = []

    for _, dong in dong_gdf.iterrows():
        # 행정동 내 격자
        dong_grids = grid_gdf[grid_gdf.within(dong.geometry)]
        total_pop = dong_grids['val'].sum()

        # 버퍼 내 공원이 있는 격자
        covered_pop = 0
        for _, grid in dong_grids.iterrows():
            grid_centroid = grid.geometry.centroid

            # 주변 공원 확인
            for _, park in park_gdf.iterrows():
                buffer = park.geometry.buffer(buffer_distance / 111000)  # 도 단위 변환

                if grid_centroid.within(buffer):
                    covered_pop += grid['val']
                    break  # 하나라도 있으면 카운트

        coverage = (covered_pop / total_pop * 100) if total_pop > 0 else 0

        results.append({
            'dong_name': dong['ADM_NM'],
            'total_population': total_pop,
            'covered_population': covered_pop,
            'coverage_ratio': round(coverage, 2)
        })

    return pd.DataFrame(results)
```

**해석 기준**:
| 커버리지 비율 | 평가 | 정책적 의미 |
|--------------|------|------------|
| 90% 이상 | 우수 | 거의 모든 주민이 공원 접근 가능 |
| 70~90% | 양호 | 대다수 주민 접근 가능, 일부 개선 필요 |
| 50~70% | 보통 | 사각지대 해소 필요 |
| 30~50% | 미흡 | 공원 추가 필요 |
| 30% 미만 | 매우 미흡 | 긴급 개선 |

### 4. 시군구별 비교 분석

**집계 방법**:
```python
def aggregate_to_sigungu(dong_service_gdf):
    """
    행정동 데이터를 시군구로 집계

    Returns:
    --------
    DataFrame : 시군구별 통계
    """
    sigungu_stats = dong_service_gdf.groupby('SIGUNGU_NM').agg({
        'total_population': 'sum',
        'covered_population': 'sum',
        'avg_service_per_capita': 'mean'
    }).reset_index()

    # 커버리지 비율 재계산
    sigungu_stats['coverage_ratio'] = (
        sigungu_stats['covered_population'] /
        sigungu_stats['total_population'] * 100
    ).round(2)

    # 순위
    sigungu_stats['rank'] = sigungu_stats['avg_service_per_capita'].rank(
        ascending=False
    ).astype(int)

    return sigungu_stats.sort_values('rank')
```

## 분석 알고리즘 상세

### 알고리즘 1: 격자 기반 2SFCA 분석

```python
def calculate_2SFCA_grid_based(parks_gdf, grid_gdf, buffer_distance=500):
    """
    100m 격자 기반 2SFCA 접근성 계산

    Parameters:
    -----------
    parks_gdf : GeoDataFrame
        공원 데이터
    grid_gdf : GeoDataFrame
        100m 격자 인구 데이터
    buffer_distance : int
        서비스 권역 거리 (m)

    Returns:
    --------
    GeoDataFrame : 접근성 점수가 추가된 격자 데이터
    """
    from scipy.spatial import cKDTree

    # Step 1: 공원별 공급-수요 비율 계산
    park_supply_demand_ratio = {}

    for idx, park in parks_gdf.iterrows():
        park_geom = park.geometry
        park_area_m2 = park['df_park_area_km2'] * 1_000_000

        buffer = park_geom.buffer(buffer_distance / 111000)  # 도 단위 변환

        # 버퍼 내 격자
        grids_in_buffer = grid_gdf[grid_gdf.geometry.centroid.within(buffer)]
        total_demand = grids_in_buffer['val'].sum()

        if total_demand > 0:
            R_j = park_area_m2 / total_demand  # m²/인
        else:
            R_j = 0

        park_supply_demand_ratio[idx] = R_j

    # Step 2: 격자별 접근성 점수 계산
    grid_accessibility = []

    for idx, grid in grid_gdf.iterrows():
        grid_centroid = grid.geometry.centroid
        grid_pop = grid['val']

        accessibility_score = 0

        # 격자 주변 공원 찾기
        for park_idx, park in parks_gdf.iterrows():
            buffer = park.geometry.buffer(buffer_distance / 111000)

            if grid_centroid.within(buffer):
                # 공원의 공급-수요 비율 합산
                R_j = park_supply_demand_ratio[park_idx]
                accessibility_score += R_j

        grid_accessibility.append({
            'grid_id': grid.get('gid', idx),
            'population': grid_pop,
            'geometry': grid.geometry,
            'accessibility_score': round(accessibility_score, 4)
        })

    return gpd.GeoDataFrame(grid_accessibility, crs=grid_gdf.crs)
```

### 알고리즘 2: 행정동별 집계

```python
def aggregate_grid_to_dong(grid_with_access, dong_gdf):
    """
    격자 접근성 데이터를 행정동 단위로 집계

    Returns:
    --------
    GeoDataFrame : 행정동별 평균 서비스 점수
    """
    # Spatial Join (격자 중심점이 어느 행정동에 속하는지)
    grid_with_dong = gpd.sjoin(
        grid_with_access.copy(),
        dong_gdf[['ADM_NM', 'SIGUNGU_NM', 'geometry']],
        how='left',
        predicate='within'
    )

    # 인구 가중 평균 계산
    dong_results = []

    for dong_name in grid_with_dong['ADM_NM'].dropna().unique():
        dong_grids = grid_with_dong[grid_with_dong['ADM_NM'] == dong_name]
        total_pop = dong_grids['population'].sum()

        if total_pop > 0:
            # 인구 가중 평균
            weighted_avg_score = (
                dong_grids['accessibility_score'] * dong_grids['population']
            ).sum() / total_pop
        else:
            weighted_avg_score = dong_grids['accessibility_score'].mean()

        dong_results.append({
            'ADM_NM': dong_name,
            'SIGUNGU_NM': dong_grids['SIGUNGU_NM'].iloc[0],
            'grid_count': len(dong_grids),
            'total_population': int(total_pop),
            'avg_service_per_capita': round(weighted_avg_score, 2),
            'geometry': dong_gdf[dong_gdf['ADM_NM'] == dong_name].iloc[0].geometry
        })

    result_gdf = gpd.GeoDataFrame(dong_results, crs=dong_gdf.crs)

    # 순위 계산
    result_gdf['service_rank'] = result_gdf['avg_service_per_capita'].rank(
        ascending=False, method='min'
    ).astype(int)

    return result_gdf.sort_values('service_rank')
```

**정책적 의미**:
- 시군구 내부의 공원 서비스 불평등 식별
- 평균 점수가 높더라도 내부 격차가 큰 지역 발견
- 세밀한 공원 확충 정책 수립 근거

**지니계수 계산 (시군구별)**:
```python
# 시군구 내 행정동별 점수를 오름차순 정렬
scores = [dong1_score, dong2_score, ..., dongN_score]
sorted_scores = sorted(scores)

# 지니계수 계산
n = len(sorted_scores)
numerator = 2 * sum((i+1) * score for i, score in enumerate(sorted_scores))
denominator = n * sum(sorted_scores)
gini = numerator / denominator - (n + 1) / n
```

### 백분위수 기반 시각화

**문제 해결**:
- 기존: 고정 범위 (0~100)로 색상 매핑 → 대부분 지역이 흰색
- 개선: 10%~90% 백분위수 기반 스케일 → 미세한 차이 시각화

**구현**:
```python
# 백분위수 계산
p10 = np.percentile(values, 10)   # 하위 10% 임계값
p90 = np.percentile(values, 90)   # 상위 10% 임계값

# Plotly Choroplethmapbox에 적용
fig.add_trace(go.Choroplethmapbox(
    zmin=p10,  # 색상 스케일 최소값
    zmax=p90,  # 색상 스케일 최대값
    colorbar=dict(
        tickvals=[p10, p25, p50, p75, p90],
        ticktext=[f'{p10:.1f}', f'{p25:.1f}', ...]
    )
))
```
